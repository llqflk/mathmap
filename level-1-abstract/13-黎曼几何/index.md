# 球面点(1,0,0)切向量(0,1,0)

```mathematica
(* Mathematica：球面切空间 *)
(* 球面 S^2 参数化 *)
sphere = {Sin[θ] Cos[φ], Sin[θ] Sin[φ], Cos[θ]};
(* 切向量基底 *)
eθ = D[sphere, θ];  eφ = D[sphere, φ];
(* 在点(1,0,0)即(θ=π/2, φ=0)处 *)
eθ /. {θ -> Pi/2, φ -> 0}           (* {0, 0, -1} *)
eφ /. {θ -> Pi/2, φ -> 0}           (* {0, 1, 0} *)
```
