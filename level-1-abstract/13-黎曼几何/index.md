### 14. 黎曼几何 / 微分几何

- 范畴：$\mathbf{Riem}$ 黎曼流形范畴

- **对象例子**：单位球面

- **态射例子**：球面测地线

- **核心函子实例**：切丛函子（球面每点→切平面）

- **Python 示例（球面切向量）**

```python
import numpy as np
# 球面点(1,0,0)切向量(0,1,0)
```

```mathematica
(* Mathematica：球面切空间 *)
(* 球面 S^2 参数化 *)
sphere = {Sin[θ] Cos[φ], Sin[θ] Sin[φ], Cos[θ]};
(* 切向量基底 *)
eθ = D[sphere, θ];  eφ = D[sphere, φ];
(* 在点(1,0,0)即(θ=π/2, φ=0)处 *)
eθ /. {θ -> Pi/2, φ -> 0}           (* {0, 0, -1} *)
eφ /. {θ -> Pi/2, φ -> 0}           (* {0, 1, 0} *)
```
