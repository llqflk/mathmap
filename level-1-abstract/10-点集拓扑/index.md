### 11. 点集拓扑

- 范畴：$\mathbf{Top}$ 拓扑空间范畴

- **对象例子**：实数轴 $\mathbb R$（通常拓扑）

- **态射例子**：连续函数 $f(x)=x^2$

- **核心函子实例**：紧致化函子

- **Python 示例（连续函数）**

```python
f = lambda x: x**2
# 连续：x微小变化→f微小变化
```

```mathematica
(* Mathematica：拓扑空间示例 *)
f[x_] := x^2
(* 原像为开：f^{-1}[(1,4)] = (-2,-1)∪(1,2) 是开集 *)
Reduce[1 < f[x] < 4, x]            (* -2 < x < -1 || 1 < x < 2 *)
(* 紧致化: 单位区间同胚于单点紧致化的R *)
```
