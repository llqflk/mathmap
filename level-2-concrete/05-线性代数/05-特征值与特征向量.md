> $Av=\lambda v$ — 自态射 $T:V\to V$ 的**不变子空间**。特征值是态射的"DNA"。

---

## 5.1 定义与特征方程

$Av=\lambda v$（$v\neq0$）。$\lambda$ 特征值，$v$ 特征向量。

$\det(A-\lambda I)=0$ 给出特征方程。$p_A(\lambda)=\det(\lambda I-A)$ 是特征多项式（monic）。

**代数重数** $m_a(\lambda)=$ 多项式根的重数；**几何重数** $m_g(\lambda)=\dim\ker(A-\lambda I)$。

总有 $1\le m_g(\lambda)\le m_a(\lambda)$。等号全成立 $\iff$ $A$ 可对角化（半单）。

**本章代码约定**（下文示例沿用这两个导入）

```python
import numpy as np
import matplotlib.pyplot as plt
```

```python
# 可视化：特征向量 = 不变方向
A = np.array([[2, 0.5], [0.5, 2]])
vals, vecs = np.linalg.eigh(A)
circle = np.array([[np.cos(t), np.sin(t)] for t in np.linspace(0, 2*np.pi, 200)])
transformed = (A @ circle.T).T

fig, ax = plt.subplots(figsize=(7, 7))
ax.fill(circle[:,0], circle[:,1], alpha=0.15, color='blue', label='单位圆')
ax.fill(transformed[:,0], transformed[:,1], alpha=0.3, color='red', label='A·(单位圆)')
for i in range(2):
    v = vecs[:, i] * 3
    ax.quiver(0, 0, v[0], v[1], angles='xy', scale_units='xy', scale=1, width=0.04, color='purple')
    ax.quiver(0, 0, -v[0], -v[1], angles='xy', scale_units='xy', scale=1, width=0.04, color='purple', alpha=0.3)
    ax.text(v[0]*1.3, v[1]*1.3, f'λ={vals[i]:.1f}', fontsize=11)
ax.set_aspect('equal'); ax.set_xlim(-5,5); ax.set_ylim(-5,5)
ax.set_title('特征向量：A作用后方向不变(仅拉伸)'); ax.legend(); ax.grid(True)
plt.show()
```

## 5.2 谱的基本定理

$\mathrm{tr}(A)=\sum\lambda_i$（迹 = 特征值和），$\det A=\prod\lambda_i$（行列式 = 特征值积）。

**Cayley-Hamilton**：$p_A(A)=0$——每个方阵满足自己的特征方程。这意味 $A^n$ 可表示为 $I,A,\dots,A^{n-1}$ 的线性组合。

**谱映射**：$f(A)$ 特征值 = $f(\lambda_i)$。

**Gershgorin 圆盘**：$\lambda$ 必落在某个以 $a_{ii}$ 为心、$R_i=\sum_{j\neq i}|a_{ij}|$ 为半径的圆盘中。不需计算特征值就能定位。

```python
# Gershgorin 圆盘可视化
A = np.array([[4, 0.8, 0.5], [0.3, -3, 0.4], [0.6, 0.2, 6]], dtype=float)
vals = np.linalg.eigvals(A)

fig, ax = plt.subplots(figsize=(8, 8))
colors = ['blue', 'red', 'green']
for i in range(3):
    c = A[i,i]; r = np.sum(np.abs(A[i,:])) - np.abs(c)
    circle = plt.Circle((c, 0), r, fill=False, color=colors[i], linewidth=2)
    ax.add_patch(circle); ax.plot(c, 0, 'o', color=colors[i], markersize=8)
ax.scatter(vals.real, vals.imag, s=120, c='purple', marker='*', zorder=5, label='特征值')
ax.axhline(0, color='gray', alpha=0.3); ax.axvline(0, color='gray', alpha=0.3)
ax.set_xlim(-6, 9); ax.set_ylim(-3, 3); ax.set_aspect('equal')
ax.set_xlabel('Re(λ)'); ax.set_ylabel('Im(λ)'); ax.legend(); ax.grid(True)
ax.set_title('Gershgorin 圆盘定位特征值')
plt.show()
```

## 5.3 幂迭代与 QR 算法

**幂迭代**：$v_{k+1}=Av_k/\|Av_k\|$ → Rayleigh 商 $\to\lambda_{\max}$。收敛速率 $|\lambda_2/\lambda_1|^k$。

**QR 算法**（求全谱）：$A_0=A$，$Q_kR_k=A_k$，$A_{k+1}=R_kQ_k$ → 收敛到实 Schur 形（对角块 1×1 或 2×2）。引入 shift 策略可加速到三次收敛。

```python
# 幂迭代收敛可视化
A = np.array([[4, 1], [2, 3]]); v = np.random.randn(2); v /= np.linalg.norm(v)
lams = []
for k in range(40):
    v = A @ v; v /= np.linalg.norm(v)
    lams.append((v @ A @ v) / (v @ v))

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(lams, 'b-o', markersize=4)
ax.axhline(max(np.linalg.eigvals(A).real), color='red', linestyle='--', label=f'真值={max(np.linalg.eigvals(A)):.4f}')
ax.set_xlabel('迭代步'); ax.set_ylabel('Rayleigh商'); ax.legend(); ax.grid(True)
ax.set_title('幂迭代收敛'); plt.show()
```

**范畴论**：特征值研究 $\mathbf{Vect}_k$ 中自态射的谱。$V=\bigoplus E_{\lambda_i}$（半单）对应 $\mathbb C[x]$-模的无挠性。$\mathrm{Spec}:\mathrm{End}(V)\to k^n/S_n$ 定义"谱函子"——将态射映射为无序特征值组。对称多项式不变量（迹、行列式）来自这个函子的伴随结构。
