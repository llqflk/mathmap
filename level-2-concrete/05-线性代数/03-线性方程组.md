# 第 3 章：线性方程组

> $Ax=b$ 是态射的纤维问题。本章连接 Gauss 消元（算法）与核-像分解（范畴论），并系统讨论 LU/Cholesky、迭代法与病态问题。

---

## 3.1 问题的三种表述

| 视角 | 表述 | 核心问题 |
|---|---|---|
| 方程组 | $\sum_j a_{ij}x_j=b_i$ | 找数值解 |
| 矩阵 | $Ax=b$ | 求态射的纤维 |
| 线性组合 | $\sum_j x_j\mathbf a_j=b$ | $b$ 是否在 $C(A)$ 中？ |

**Rouché-Capelli 定理**：解存在 $\iff\mathrm{rank}(A)=\mathrm{rank}([A\mid b])$。

```python
import numpy as np
import matplotlib.pyplot as plt

# 可视化：R² 中三种情况
fig, axes = plt.subplots(1, 3, figsize=(15, 5))
x = np.linspace(-2, 5, 100)

# 唯一解
axes[0].plot(x, 3-x, 'b-', linewidth=2, label='x+y=3')
axes[0].plot(x, 2*x-1, 'r-', linewidth=2, label='2x-y=1')
A = np.array([[1,1],[2,-1]]); b = np.array([3,1])
sol = np.linalg.solve(A, b)
axes[0].plot(sol[0], sol[1], 'o', color='purple', markersize=12)
axes[0].set_title(f'唯一解 ({sol[0]:.1f},{sol[1]:.1f})'); axes[0].legend(); axes[0].grid(True)

# 无穷多解
axes[1].plot(x, 2-x, 'b-', linewidth=2, label='x+y=2')
axes[1].plot(x, 2-x, 'r--', linewidth=2, label='2x+2y=4 (重合)')
axes[1].set_title('无穷多解 (rank=1, n=2)'); axes[1].legend(); axes[1].grid(True)

# 无解
axes[2].plot(x, 2-x, 'b-', linewidth=2, label='x+y=2')
axes[2].plot(x, 5-x, 'r-', linewidth=2, label='x+y=5 (平行)')
axes[2].set_title('无解 (rank(A)<rank([A|b]))'); axes[2].legend(); axes[2].grid(True)
for ax in axes: ax.set_xlim(-2, 5); ax.set_ylim(-2, 5); ax.set_aspect('equal')
plt.tight_layout(); plt.show()
```

## 3.2 Gauss 消元与 LU 分解

Gauss 消元 = 将 $A$ 化为上三角 $U$。每步 = 左乘初等矩阵 $E_{ij}(\alpha)$。

$PA=LU$：$P$ 排列矩阵，$L$ 单位下三角，$U$ 上三角。消元过程的代数量 = $L$ 的严格下三角部分。

**部分选主元**（Partial Pivoting）：每步选当前列最大绝对值元素为主元。避免"小主元除以大数"的灾难性抵消。

**复杂度**：直接法 $O(n^3)$。对于 $A$ 固定、$b$ 多变的情况，一次分解 + $O(n^2)$ 求解 = 极大节省。

```python
from scipy.linalg import lu

A = np.array([[2, 1, -1], [-3, -1, 2], [-2, 1, 2]], dtype=float)
P, L, U = lu(A)
b = np.array([8, -11, -3], dtype=float)

# 可视化 LU 分解
fig, axes = plt.subplots(1, 4, figsize=(20, 5))
mats = [A, P, L, U]; titles = ['A', 'P (排列)', 'L (下三角)', 'U (上三角)']
for ax, mat, title in zip(axes, mats, titles):
    im = ax.imshow(np.round(mat, 2), cmap='coolwarm', vmin=-3, vmax=3)
    ax.set_title(title)
    for i in range(mat.shape[0]):
        for j in range(mat.shape[1]):
            ax.text(j, i, f'{mat[i,j]:.1f}', ha='center', va='center', fontsize=8)
    plt.colorbar(im, ax=ax, shrink=0.7)
print(f'PA=LU? {np.allclose(P@A, L@U)}')
plt.tight_layout(); plt.show()
```

## 3.3 Cholesky 分解（对称正定加速）

若 $A=A^\top\succ0$（正定），可用 $A=LL^\top$（$L$ 下三角，对角元 $>0$）。

**Cholesky vs LU**：运算量减半（$\frac13n^3$ vs $\frac23n^3$），无需选主元，数值更稳定。

**正定判定**：所有顺序主子式 $>0\iff$ 所有特征值 $>0\iff$ 存在 Cholesky 分解。

```python
from scipy.linalg import cholesky, eigh

A_spd = np.array([[4, 2, 2], [2, 5, 3], [2, 3, 6]], dtype=float)
L = cholesky(A_spd, lower=True)

fig, axes = plt.subplots(1, 3, figsize=(15, 5))
for ax, (mat, title) in zip(axes, [(A_spd,'A (对称正定)'), (L,'L'), (L@L.T,'LL^T')]):
    im = ax.imshow(mat, cmap='coolwarm')
    for i in range(3):
        for j in range(3):
            ax.text(j, i, f'{mat[i,j]:.1f}', ha='center', va='center', fontsize=11)
    ax.set_title(title); plt.colorbar(im, ax=ax, shrink=0.8)
# 验证顺序主子式
for k in range(1,4):
    print(f'Δ_{k} = {np.linalg.det(A_spd[:k,:k]):.1f} > 0 ✓')
plt.tight_layout(); plt.show()
```

## 3.4 条件数与病态

$\kappa_p(A)=\|A\|_p\cdot\|A^{-1}\|_p$。$\kappa\approx 10^k$ → 丢约 $k$ 位精度。

**Hilbert 矩阵** $H_{ij}=1/(i+j-1)$：$\kappa(H_{10})\approx 10^{13}$。

**误差放大**：$\frac{\|\Delta x\|}{\|x\|}\le\kappa(A)\frac{\|\Delta b\|}{\|b\|}$。

```python
from scipy.linalg import hilbert

ns = np.arange(2, 14)
kappas = [np.linalg.cond(hilbert(n), 2) for n in ns]

fig, ax = plt.subplots(figsize=(8, 5))
ax.semilogy(ns, kappas, 'ro-', linewidth=2, markersize=8)
for n, k in zip(ns, kappas):
    ax.annotate(f'{k:.1e}', (n, k), fontsize=7, rotation=45, ha='left')
ax.set_xlabel('矩阵阶数 n'); ax.set_ylabel('κ₂(H_n)')
ax.set_title('Hilbert 矩阵条件数'); ax.grid(True)
plt.show()
```

  Joined->True, PlotMarkers->Automatic, AxesLabel->{"n","κ(H_n)"}]

## 3.5 迭代法

大型稀疏矩阵直接 $O(n^3)$ 不可接受。迭代法 $O(k\cdot\mathrm{nnz})$，$k$ 为迭代步数。

| 方法 | 迭代公式 | 适用条件 |
|---|---|---|
| Jacobi | $x^{(k+1)}=D^{-1}(b-(L+U)x^{(k)})$ | 严格对角占优 |
| Gauss-Seidel | $x^{(k+1)}=(D+L)^{-1}(b-Ux^{(k)})$ | 正定或对角占优 |
| 共轭梯度 (CG) | Krylov 子空间能量极小化 | 对称正定 |
| GMRES | Arnoldi + 最小化残差 | 一般非对称 |

**CG 收敛速率**：$\|x_k-x^*\|_A\le2\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k\|x_0-x^*\|_A$。

```python
from scipy.sparse.linalg import cg
from scipy.sparse import diags

n = 500; e = np.ones(n)
A_sp = diags([-e, 2*e, -e], [-1, 0, 1], shape=(n, n))
b_sp = np.ones(n)

residuals = []
def cb(xk): residuals.append(np.linalg.norm(A_sp @ xk - b_sp))
x, info = cg(A_sp, b_sp, rtol=1e-8, callback=cb)

fig, ax = plt.subplots(figsize=(8, 5))
ax.semilogy(residuals[:60], 'b-o', markersize=3)
ax.set_xlabel('迭代步数'); ax.set_ylabel('||Ax-b||')
ax.set_title(f'CG 收敛 ({len(residuals)}步)'); ax.grid(True)
plt.show()
```

```mathematica
(* CG 迭代 *)
A = SparseArray[{Band[{1,1}]->2,Band[{2,1}]->-1,Band[{1,2}]->-1},{500,500}];
b = ConstantArray[1, 500];
res = Reap[LinearSolve[A,b,Method->"Krylov",MaxIterations->50,
  ResidualNormFunction->(Sow[Norm[#]]&)]][[2,1]];
ListLogPlot[res, Joined->True, AxesLabel->{"迭代","残差"}]
```

**范畴论**：$Ax=b$ 是态射 $A$ 的纤维。$A^{-1}(b)=x_p+\ker A$ 是仿射子空间。Gauss消元 = 态射三角化。条件数 = 态射"不可逆程度"。最小二乘需要 $\mathbf{Hilb}_{\text{fd}}$ 的正交投影——纯 $\mathbf{Vect}_k$ 不够。
