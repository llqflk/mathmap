# 第 6 章：内积空间

> 内积将"几何"引入向量空间——长度、角度、正交。$\mathbf{Vect}_k$ 升级为 **$\mathbf{Hilb}_{\text{fd}}$**——dagger 范畴。

## 6.1 内积定义

$\langle\cdot,\cdot\rangle:V\times V\to\mathbb R$ 满足对称、双线性、正定性。

**诱导概念**：范数 $\|v\|=\sqrt{\langle v,v\rangle}$，距离 $d(u,v)=\|u-v\|$，角度 $\cos\theta=\frac{\langle u,v\rangle}{\|u\|\|v\|}$。

**Cauchy-Schwarz**：$|\langle u,v\rangle|\le\|u\|\cdot\|v\|$，等号 $\iff u,v$ 线性相关。

**极化恒等式**（实数）：$\langle u,v\rangle=\frac14(\|u+v\|^2-\|u-v\|^2)$。**范数唯一决定内积！**

```python
# 可视化：内积 = 投影长度 × 另一向量长度
fig, axes = plt.subplots(1, 2, figsize=(12, 5))
u = np.array([3, 0]); angles = [0, np.pi/6, np.pi/3, np.pi/2, 2*np.pi/3]
for theta in angles:
    v = 3 * np.array([np.cos(theta), np.sin(theta)])
    inner = u @ v
    axes[0].quiver(0, 0, v[0], v[1], angles='xy', scale_units='xy', scale=1, alpha=0.6, width=0.02)
    proj = (inner / (np.linalg.norm(u)**2)) * u
    axes[0].quiver(0, 0, proj[0], proj[1], angles='xy', scale_units='xy', scale=1, color='red', alpha=0.4, width=0.02)
    axes[0].text(v[0]*1.1, v[1]*1.1, f'<u,v>={inner:.1f}', fontsize=8)
axes[0].quiver(0, 0, u[0], u[1], angles='xy', scale_units='xy', scale=1, color='b', width=0.04, label='u')
axes[0].set_xlim(-4, 5); axes[0].set_ylim(-2, 4); axes[0].set_aspect('equal')
axes[0].set_title('内积 = 投影 × ||u||'); axes[0].legend(); axes[0].grid(True)

# Cauchy-Schwarz
th = np.linspace(0, 2*np.pi, 200)
bound = [np.linalg.norm(u)*3 for _ in th]
axes[1].polar(th, [abs(u @ (3*np.array([np.cos(t), np.sin(t)]))) for t in th], 'b-', linewidth=2, label='|<u,v>|')
axes[1].polar(th, bound, 'r--', linewidth=2, label='||u||·||v||')
axes[1].legend(); axes[1].set_title('Cauchy-Schwarz')
plt.tight_layout(); plt.show()
```

## 6.2 范数与单位球

| 范数 | 公式 | 单位球 | 来自内积？ |
|---|---|---|---|
| $\ell_1$ | $\sum|x_i|$ | 菱形 | ❌ |
| $\ell_2$ | $\sqrt{\sum x_i^2}$ | 球 | ✅ |
| $\ell_\infty$ | $\max|x_i|$ | 正方体 | ❌ |
| Frobenius | $\sqrt{\sum a_{ij}^2}=\sqrt{\sum\sigma_i^2}$ | 超球 | ✅ |

```python
# 三种范数的单位球
fig, axes = plt.subplots(1, 3, figsize=(15,5))
t = np.linspace(0, 2*np.pi, 300)
for ax, p, title, c in zip(axes, [1, 2, np.inf],
    ['ℓ₁ 菱形', 'ℓ₂ 圆 (内积)', 'ℓ∞ 正方形'], ['red', 'blue', 'green']):
    if p == np.inf:
        ball = np.array([[np.cos(ti)/max(abs(np.cos(ti)),abs(np.sin(ti))),
                           np.sin(ti)/max(abs(np.cos(ti)),abs(np.sin(ti)))] for ti in t])
    elif p == 1:
        ball = np.array([[np.cos(ti)/(abs(np.cos(ti))+abs(np.sin(ti))),
                           np.sin(ti)/(abs(np.cos(ti))+abs(np.sin(ti)))] for ti in t])
    else:
        ball = np.column_stack([np.cos(t), np.sin(t)])
    ax.fill(ball[:,0], ball[:,1], alpha=0.3, color=c)
    ax.set_aspect('equal'); ax.set_xlim(-1.5,1.5); ax.set_ylim(-1.5,1.5)
    ax.set_title(title); ax.grid(True)
plt.tight_layout(); plt.show()
```

## 6.3 伴随算子

$\langle Tv,w\rangle_W=\langle v,T^*w\rangle_V$ 唯一确定伴随 $T^*$。

**像-核对偶**：$\ker T^*=(\mathrm{im}\,T)^\perp$，$\mathrm{im}\,T^*=(\ker T)^\perp$。

**自伴** $T^*=T$（对称矩阵）；**酉** $T^*=T^{-1}$（正交矩阵）；**正规** $T^*T=TT^*$。

```python
# 伴随：<Ax, y> = <x, A^T y> 的数值验证
A = np.array([[1, 2, 3], [4, 5, 6]], dtype=float)
x = np.array([1, 1, 1.])
y = np.array([1, 1.])
lhs = np.dot(A @ x, y); rhs = np.dot(x, A.T @ y)
print(f'<Ax,y>={lhs}, <x,A^Ty>={rhs}, 相等: {abs(lhs-rhs)<1e-10}')
```

```mathematica
(* 伴随验证 *)
A = {{1,2,3},{4,5,6}}; x = {1,1,1}; y = {1,1};
(A.x).y == x.(Transpose[A].y)
```

**范畴论**：$(-)^\dagger:\mathbf{Hilb}_{\text{fd}}^{op}\to\mathbf{Hilb}_{\text{fd}}$ 是 dagger 函子。$\mathbf{Hilb}_{\text{fd}}$ 区别于 $\mathbf{Vect}_k$ 的关键：正交补 $U^\perp$ 由内积典范确定，这使谱定理（第8章）成立。
