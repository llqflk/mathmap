# 第 7 章：正交性与 Gram-Schmidt

> Gram-Schmidt = 态射的 QR 分解。正交投影 = $\mathbf{Hilb}_{\text{fd}}$ 中的分裂幂等元。

---

## 7.1 正交性与正交补

$u\perp v\iff\langle u,v\rangle=0$。$U^\perp=\{v\mid\forall u\in U:\langle u,v\rangle=0\}$。

$V=U\oplus U^\perp$（有限维）且 $(U^\perp)^\perp=U$。**正交补是唯一的补——$\mathbf{Hilb}_{\text{fd}}$ 的独有结构。**

**Bessel 不等式**：对单位正交组 $\{q_i\}$，$\sum|\langle v,q_i\rangle|^2\le\|v\|^2$。

**Parseval 恒等式**：若 $\{q_i\}$ 是单位正交基，则 $\sum|\langle v,q_i\rangle|^2=\|v\|^2$。

```python
# 3D 正交补
fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')
n = np.array([2, 1, -1])
xx, yy = np.meshgrid(np.linspace(-2, 2, 10), np.linspace(-2, 2, 10))
zz = 2*xx + yy
ax.plot_surface(xx, yy, zz, alpha=0.3, color='blue')
# U的两个基向量
u1 = np.array([1,-2,0]); u1 = u1/np.linalg.norm(u1)*3
u2 = np.array([0,1,1]); u2 = u2/np.linalg.norm(u2)*3
ax.quiver(0,0,0,u1[0],u1[1],u1[2],color='green',linewidth=2)
ax.quiver(0,0,0,u2[0],u2[1],u2[2],color='green',linewidth=2)
ax.quiver(0,0,0,n[0],n[1],n[2],color='red',linewidth=3,label='法向量 = U⊥')
ax.set_xlabel('X'); ax.set_ylabel('Y'); ax.set_zlabel('Z')
ax.set_title('R³ = U(平面) ⊕ U⊥(法线)'); ax.legend()
plt.show()
```

## 7.2 Gram-Schmidt 与 QR 分解

$u_k=v_k-\sum_{j<k}\langle v_k,q_j\rangle q_j$，$q_k=u_k/\|u_k\|$。

**矩阵形式**：$A=QR$，$Q^\top Q=I$（列正交），$R$ 上三角。$r_{ij}=\langle q_i,v_j\rangle$（$i\le j$）。

```python
# Gram-Schmidt 逐步可视化
v = np.random.randn(2,3)*2; v1, v2 = v[0], v[1]
u1 = v1; q1 = u1/np.linalg.norm(u1)
u2 = v2 - np.dot(v2,q1)*q1; q2 = u2/np.linalg.norm(u2)

fig, axes = plt.subplots(1, 2, figsize=(12,5))
axes[0].quiver(0,0,v1[0],v1[1],angles='xy',scale_units='xy',scale=1,color='b',width=0.04,label='v₁')
axes[0].quiver(0,0,v2[0],v2[1],angles='xy',scale_units='xy',scale=1,color='r',width=0.04,label='v₂')
axes[0].set_xlim(-5,5); axes[0].set_ylim(-5,5); axes[0].set_aspect('equal')
axes[0].set_title('原始向量'); axes[0].legend(); axes[0].grid(True)
axes[1].quiver(0,0,q1[0],q1[1],angles='xy',scale_units='xy',scale=1,color='b',width=0.04,label='q₁')
axes[1].quiver(0,0,q2[0],q2[1],angles='xy',scale_units='xy',scale=1,color='r',width=0.04,label='q₂')
proj = np.dot(v2,q1)*q1; axes[1].plot([proj[0],v2[0]],[proj[1],v2[1]],'k--',alpha=0.5)
axes[1].set_xlim(-2,5); axes[1].set_ylim(-2,3); axes[1].set_aspect('equal')
axes[1].set_title(f'Gram-Schmidt: <q₁,q₂>={np.dot(q1,q2):.2e}'); axes[1].legend(); axes[1].grid(True)
plt.tight_layout(); plt.show()
```

## 7.3 正交投影与最佳逼近

$P_U(v)=\sum\langle v,q_j\rangle q_j=QQ^\top v$。$P_U$ 幂等且对称。

**最佳逼近**：$P_U(v)=\arg\min_{u\in U}\|v-u\|$。残差 $v-P_U(v)\perp U$。

```python
# 正交投影 = 最近点
line_dir = np.array([1,1])/np.sqrt(2); P_line = np.outer(line_dir, line_dir)
pts = np.random.uniform(-2,2,(12,2)); proj_pts = (P_line @ pts.T).T

fig, axes = plt.subplots(1, 2, figsize=(12,5))
axes[0].scatter(pts[:,0],pts[:,1],c='blue',s=40,alpha=0.6)
axes[0].scatter(proj_pts[:,0],proj_pts[:,1],c='red',s=60,zorder=5)
for p,pp in zip(pts,proj_pts):
    axes[0].plot([p[0],pp[0]],[p[1],pp[1]],'k--',alpha=0.3)
axes[0].plot([-3,3],[-3,3],'g-',alpha=0.5,label='子空间U'); axes[0].set_aspect('equal')
axes[0].set_xlim(-3,3); axes[0].set_ylim(-3,3); axes[0].set_title('正交投影 = 最短距离'); axes[0].legend(); axes[0].grid(True)

# 误差分析
theta = np.linspace(0,np.pi,200)
errors = [np.linalg.norm(np.array([np.cos(t),np.sin(t)]) - P_line @ np.array([np.cos(t),np.sin(t)])) for t in theta]
axes[1].polar(theta, errors, 'b-', linewidth=2)
axes[1].set_title('投影误差随方向变化')
plt.tight_layout(); plt.show()
```

---
**范畴论**：正交投影 $P$ 是 $\mathbf{Hilb}_{\text{fd}}$ 中的**分裂幂等元**（$P^\dagger=P$，$P^2=P$）。$\mathrm{im}\,P$ 是子对象，$\ker P=(\mathrm{im}\,P)^\perp$ 是其唯一补。这是 Hilbert 范畴的核心特征。
