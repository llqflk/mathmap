## 10.1 二次型与对称双线性形式

$Q(x)=x^\top Ax=\sum a_{ij}x_i x_j$（$A^\top=A$）。极化：$B(x,y)=\frac14(Q(x+y)-Q(x-y))=x^\top Ay$。

**合同变换** $A\mapsto P^\top AP$ 保持二次型但改变坐标表示。合同 $\neq$ 相似。

**本章代码约定**（下文示例沿用这两个导入）

```python
import numpy as np
import matplotlib.pyplot as plt
```

```python
# 二次型等高线：正定 vs 不定
def plot_quadratic(A, title):
    x, y = np.linspace(-3, 3, 100), np.linspace(-3, 3, 100)
    X, Y = np.meshgrid(x, y); Z = A[0,0]*X**2 + 2*A[0,1]*X*Y + A[1,1]*Y**2
    fig, ax = plt.subplots(figsize=(6,6))
    cs = ax.contour(X, Y, Z, levels=20, cmap='coolwarm')
    ax.clabel(cs, inline=True, fontsize=7); ax.set_aspect('equal')
    ax.set_title(title); ax.grid(True); return ax

plot_quadratic(np.array([[2, 0.5], [0.5, 1]]), '正定: 椭圆等高线')
plt.show()
plot_quadratic(np.array([[1, 2], [2, -1]]), '不定: 双曲线 (马鞍面)')
plt.show()
```

## 10.2 Sylvester 惯性律与正定性

**惯性指数** $(p,q,z)$ 在合同变换下不变。规范形 $\mathrm{diag}(I_p,-I_q,0_z)$。

**正定判定**：所有特征值 >0 $\iff$ 所有顺序主子式 >0 $\iff$ 存在 Cholesky 分解。

**二次超曲面分类**：$(3,0,0)$ 椭球；$(2,1,0)$ 单叶双曲面；$(1,2,0)$ 双叶双曲面。

```python
from mpl_toolkits.mplot3d import Axes3D
fig = plt.figure(figsize=(15, 5))

configs = [((3,0,0), np.diag([1,1,1]), '椭球面'),
           ((2,1,0), np.diag([1,1,-1]), '单叶双曲面')]
for idx, ((p,q,z), D, title) in enumerate(configs):
    ax = fig.add_subplot(1, 2, idx+1, projection='3d')
    u, v = np.linspace(-2,2,40), np.linspace(0,2*np.pi,40)
    U, V = np.meshgrid(u, v)
    X = np.cosh(U) * np.cos(V); Y = np.cosh(U) * np.sin(V)
    if q>0: Z = np.sinh(U)
    else: Z = np.sqrt(np.maximum(0, 1 - X**2 - Y**2))
    ax.plot_surface(X, Y, Z, alpha=0.5); ax.plot_surface(X, Y, -Z, alpha=0.5)
    ax.set_xlabel('X'); ax.set_ylabel('Y'); ax.set_zlabel('Z'); ax.set_title(f'{title} ({p},{q},{z})')
plt.tight_layout(); plt.show()
```

## 10.3 同时对角化（广义特征值问题）

$Ax=\lambda Mx$（$M\succ0$）。存在 $P$ 使 $P^\top MP=I$，$P^\top AP=\Lambda$。

**应用**：振动分析——$M$ 质量矩阵，$A$ 刚度矩阵，$\sqrt{\lambda_i}=$ 固有频率。

```python
M = np.array([[2, 0], [0, 1]], dtype=float); A = np.array([[3, 0.5], [0.5, 2]], dtype=float)
# numpy 没有广义特征值求解器，先用 Cholesky 把 A v = λ M v 化成标准问题：
#   M = L Lᵀ, v = L⁻ᵀ u  ⟹  (L⁻¹ A L⁻ᵀ) u = λ u
L = np.linalg.cholesky(M)
C = np.linalg.solve(L, A) @ np.linalg.inv(L).T
gen_vals, U = np.linalg.eigh(C)
gen_vecs = np.linalg.solve(L.T, U)          # 换回原坐标
print(f'广义特征值: {np.round(gen_vals, 4)}')
# 验证：A v = λ M v，且特征向量关于 M 正交
v = gen_vecs[:, 0]; lam = gen_vals[0]
print(f'||Av - λMv|| = {np.linalg.norm(A @ v - lam * (M @ v)):.2e}')
print(f'vᵀMv = {v @ M @ v:.2f},  vᵀM u = {v @ M @ gen_vecs[:, 1]:.2e}')
```

**范畴论**：二次型 $Q\leftrightarrow$ 对称双线性形式 $B\leftrightarrow$ 结构态射 $\flat_B:V\to V^*$。合同变换 = $\flat_B$ 在基变换下。正定 $\flat_B$ 同构 → Riesz 表示 $\cong\mathbf{Hilb}_{\text{fd}}$。惯性 $(p,q,z)$ 是 $\mathrm{GL}_n$ 在对称矩阵上合同作用的轨道。
