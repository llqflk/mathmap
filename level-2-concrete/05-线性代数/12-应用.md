## 12.1 最小二乘

$\min\|Ax-b\|_2$ → $x_{LS}=(A^\top A)^{-1}A^\top b$。几何：$Ax_{LS}=P_{\mathrm{im}A}(b)$（正交投影）。

**岭回归**：$x_\lambda=(A^\top A+\lambda I)^{-1}A^\top b$。$\ell_2$ 正则化对抗病态和小样本。

**本章代码约定**（下文示例沿用这两个导入）

```python
import numpy as np
import matplotlib.pyplot as plt
```

```python
t = np.linspace(0, 5, 30); y = 2*t + 1 + 0.8*np.random.randn(30)
A = np.column_stack([t, np.ones_like(t)])
x_ls = np.linalg.lstsq(A, y, rcond=None)[0]; y_pred = A @ x_ls

fig, axes = plt.subplots(1, 2, figsize=(12, 5))
axes[0].scatter(t, y, alpha=0.5, label='数据'); axes[0].plot(t, y_pred, 'r-', linewidth=2, label=f'y={x_ls[0]:.2f}t+{x_ls[1]:.2f}')
for ti, yi, ypi in zip(t[::3], y[::3], y_pred[::3]):
    axes[0].plot([ti, ti], [yi, ypi], 'k--', alpha=0.3)
axes[0].set_xlabel('t'); axes[0].set_ylabel('y'); axes[0].set_title('最小二乘: 残差 ⊥ im(A)'); axes[0].legend(); axes[0].grid(True)

# 岭回归路径
lambdas = np.logspace(-3, 2, 60)
coeffs = np.array([np.linalg.solve(A.T@A + l*np.eye(2), A.T@y) for l in lambdas])
axes[1].semilogx(lambdas, coeffs[:,0], 'b-', label='斜率'); axes[1].semilogx(lambdas, coeffs[:,1], 'r-', label='截距')
axes[1].set_xlabel('λ'); axes[1].set_ylabel('系数'); axes[1].set_title('岭回归路径'); axes[1].legend(); axes[1].grid(True)
plt.tight_layout(); plt.show()
```

## 12.2 PCA

数据 $X_{n\times p}$ 中心化 → SVD → 前 $k$ 主成分 $Z=XV_k$。最大化方差方向。

$\sigma_i^2/(n-1)$ = 第 $i$ 主成分方差，$\sum_{i=1}^k\sigma_i^2/\sum\sigma_i^2$ = 解释方差比。

```python
X = np.random.randn(100, 2); X[:,1] = X[:,0]*2 + 0.1*np.random.randn(100)
X_c = X - X.mean(0); U, s, Vt = np.linalg.svd(X_c, full_matrices=False)
Z = X_c @ Vt[:1,:].T

fig, axes = plt.subplots(1, 2, figsize=(12,5))
axes[0].scatter(X[:,0], X[:,1], alpha=0.6, s=30)
pc = Vt[0]*s[0]/np.sqrt(99)*0.8; axes[0].quiver(X.mean(0)[0], X.mean(0)[1], pc[0], pc[1],
    angles='xy', scale_units='xy', scale=1, color='red', width=0.03, label=f'PC1 ({s[0]**2/sum(s**2):.0%})')
axes[0].set_aspect('equal'); axes[0].set_title('PCA 主方向'); axes[0].legend(); axes[0].grid(True)
axes[1].scatter(Z, np.zeros(100), alpha=0.6, s=30); axes[1].set_title('投影到PC1 (1D)')
plt.tight_layout(); plt.show()
```

## 12.3 PageRank

$r = Gr$（$G=\alpha P + \frac{1-\alpha}{n}\mathbf{1}\mathbf{1}^\top$）。幂迭代求主特征向量。

$r_i$ = 网页 $i$ 的权威分数。Perron-Frobenius 定理保证正解唯一。

```python
n=10; np.random.seed(1); adj = np.random.rand(n,n)<0.25
deg = adj.sum(0); deg[deg==0]=n; P = adj/deg
G = 0.85*P + 0.15/n * np.ones((n,n))
r = np.ones(n)/n; history=[r.copy()]
for _ in range(50): r = G @ r; history.append(r.copy())
history = np.array(history)

fig, axes = plt.subplots(1, 2, figsize=(12,5))
for i in range(n): axes[0].plot(history[:,i], alpha=0.7, linewidth=1)
axes[0].set_xlabel('迭代'); axes[0].set_ylabel('PageRank'); axes[0].set_title('幂迭代收敛'); axes[0].grid(True)
axes[1].bar(range(n), r, color=plt.cm.viridis(r/max(r)))
axes[1].set_xlabel('网页'); axes[1].set_ylabel('PageRank'); axes[1].set_title('最终排序')
plt.tight_layout(); plt.show()
```

## 12.4 谱聚类

图拉普拉斯 $L=D-A$。Fiedler 向量（$\lambda_2$ 的特征向量）做二分割。

$L$ 半正定，$\lambda_2>0\iff$ 图连通。$L$ 是 Laplace-Beltrami 算子的离散版本。

```python
n1, n2 = 8, 8; n = n1+n2
adj = np.zeros((n,n))
for i in range(n1):
    for j in range(i+1, n1): adj[i,j]=adj[j,i]=1
for i in range(n1, n):
    for j in range(i+1, n): adj[i,j]=adj[j,i]=1
adj[3,10]=adj[10,3]=1; adj[6,13]=adj[13,6]=1  # 桥接
D = np.diag(adj.sum(1)); L = D-adj
vals, vecs = np.linalg.eigh(L)
fiedler = vecs[:,1]; part = (fiedler>0).astype(int)

fig, axes = plt.subplots(1, 2, figsize=(12,5))
axes[0].bar(range(n), fiedler, color=['blue' if p==0 else 'red' for p in part])
axes[0].axhline(0, color='black'); axes[0].set_title(f'Fiedler向量 (λ₂={vals[1]:.2f})'); axes[0].grid(True)
import networkx as nx
G = nx.from_numpy_array(adj)
pos = nx.spring_layout(G, seed=42)
nx.draw(G, pos, ax=axes[1], node_color=['blue' if p==0 else 'red' for p in part],
        node_size=200, edge_color='gray', alpha=0.7)
axes[1].set_title('谱聚类结果')
plt.tight_layout(); plt.show()
```

**元模式**：四种应用都体现了**函子化思维**——构建 $F:\mathbf{Problem}\to\mathbf{Vect}_k$，在线性范畴求解（最小二乘、特征向量、SVD），再映射回原问题。$\mathbf{Vect}_k$ 是最成熟的计算范畴——这就是线代统治数据科学的原因。
