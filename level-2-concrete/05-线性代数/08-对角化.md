# 第 8 章：对角化与谱定理

> $\mathbf{Hilb}_{\text{fd}}$ 的核心定理：每个自伴态射可正交对角化。$A=Q\Lambda Q^\top$。

---

## 8.1 对角化条件

$A=P\Lambda P^{-1}$ 可对角化 $\iff\forall\lambda:\;m_g(\lambda)=m_a(\lambda)$。

$P$ 的列 = $A$ 的特征向量，$\Lambda$ = 特征值对角矩阵。

**不可对角化的根源**：$m_g<m_a$ → 存在 Jordan 块（第 9 章），特征向量不足以构成基。

```python
# 对角化：换到特征基视角
A = np.array([[2, 1], [1, 2]]); vals, P = np.linalg.eig(A); Pinv = np.linalg.inv(P)
circle = np.array([[np.cos(t), np.sin(t)] for t in np.linspace(0, 2*np.pi, 200)])

fig, axes = plt.subplots(1, 3, figsize=(15, 5))
axes[0].fill(*circle.T, alpha=0.15, color='blue')
axes[0].fill(*(A@circle.T), alpha=0.3, color='red')
axes[0].set_aspect('equal'); axes[0].set_xlim(-4,4); axes[0].set_ylim(-4,4)
axes[0].set_title('标准基: A混合旋转+拉伸'); axes[0].grid(True)

rotated = (Pinv @ circle.T).T
axes[1].fill(*circle.T, alpha=0.15, color='blue')
axes[1].fill(*rotated.T, alpha=0.3, color='green')
axes[1].set_aspect('equal'); axes[1].set_xlim(-3,3); axes[1].set_ylim(-3,3)
axes[1].set_title('P⁻¹: 转到特征基'); axes[1].grid(True)

Lambda = np.diag(vals); scaled = (Lambda @ rotated.T).T
axes[2].fill(*rotated.T, alpha=0.15, color='green')
axes[2].fill(*scaled.T, alpha=0.3, color='purple')
axes[2].set_aspect('equal'); axes[2].set_xlim(-5,5); axes[2].set_ylim(-2,2)
axes[2].set_title(f'Λ: 纯缩放 λ=({vals[0]:.0f},{vals[1]:.0f})'); axes[2].grid(True)
plt.tight_layout(); plt.show()
```

## 8.2 谱定理

**实对称 $A=A^\top$**：$A=Q\Lambda Q^\top$，$Q$ 正交，$\Lambda$ 对角，特征值全实数。

**Hermitian $A=A^*$**：$A=U\Lambda U^*$（酉对角化），特征值全实数。

**正规 $A^*A=AA^*$**：可酉对角化。这是对角化最宽泛的条件。

**谱分解**：$A=\sum\lambda_i q_i q_i^\top=\sum\lambda_j P_j$。$\{P_j\}$ 是互相正交的投影族：$P_iP_j=\delta_{ij}P_i$，$\sum P_j=I$。

```python
# 谱定理可视化：对称矩阵 → 正交特征方向
A_sym = np.array([[3, 1], [1, 3]]); vals_s, Q = np.linalg.eigh(A_sym)
circle = np.array([[np.cos(t), np.sin(t)] for t in np.linspace(0, 2*np.pi, 200)])
transformed = (A_sym @ circle.T).T

fig, ax = plt.subplots(figsize=(7,7))
ax.fill(circle[:,0],circle[:,1],alpha=0.15,color='blue')
ax.fill(transformed[:,0],transformed[:,1],alpha=0.3,color='red')
for i in range(2):
    v = Q[:,i]*3; ax.quiver(0,0,v[0],v[1],angles='xy',scale_units='xy',scale=1,width=0.04,color='purple')
    ax.quiver(0,0,-v[0],-v[1],angles='xy',scale_units='xy',scale=1,width=0.04,color='purple',alpha=0.3)
ax.set_aspect('equal'); ax.set_xlim(-6,6); ax.set_ylim(-6,6)
ax.set_title(f'谱定理: λ=({vals_s[0]},{vals_s[1]}), 特征方向正交'); ax.grid(True)
plt.show()
```

## 8.3 矩阵函数

$f(A)=Q\,f(\Lambda)\,Q^\top$。**函数演算**（functional calculus）。

$e^A$ — 微分方程；$\sqrt{A}$ — 极分解；$\log A$ — Lie 群/Lie 代数对应。

$\det(e^A)=e^{\mathrm{tr}A}$（行列式指数公式）。

```python
from scipy.linalg import expm

A_exp = np.array([[0, -1], [1, 0]]); v0 = np.array([1, 0])
t_vals = np.linspace(0, 2*np.pi, 200)
traj = np.array([expm(t*A_exp) @ v0 for t in t_vals])

fig, axes = plt.subplots(1, 2, figsize=(12,5))
axes[0].plot(traj[:,0], traj[:,1], 'b-', linewidth=2)
axes[0].scatter([1],[0],s=60,c='red',zorder=5,label='起点')
axes[0].set_aspect('equal'); axes[0].set_xlim(-1.5,1.5); axes[0].set_ylim(-1.5,1.5)
axes[0].set_title('e^{tA}·v₀ (A=旋转生成元)'); axes[0].legend(); axes[0].grid(True)

# det(e^A) = e^{tr(A)}
ns = range(2, 8)
errors = [abs(np.linalg.det(expm(np.random.randn(n,n))) - np.exp(np.trace(np.random.randn(n,n)))) for n in ns]
axes[1].semilogy(list(ns), errors, 'o-', color='purple')
axes[1].set_xlabel('n'); axes[1].set_ylabel('误差'); axes[1].set_title('det(e^A)=e^{tr(A)} 验证'); axes[1].grid(True)
plt.tight_layout(); plt.show()
```

**范畴论**：谱定理 = $\mathbf{Hilb}_{\text{fd}}$ 自伴态射的典范分解。投影值测度 $\{P_j\}$ 是交换 C\*-代数同构 $C^*(\{A\})\cong C(\sigma(A))$（Gelfand-Naimark 有限维版）。$\mathbf{Hilb}_{\text{fd}}$ 的自伴态射总是半单——这是 dagger 结构的直接推论，在纯 $\mathbf{Vect}_k$ 中不成立。
