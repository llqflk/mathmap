# 第 11 章：奇异值分解 (SVD)

> "任意矩阵可对角化"——SVD 对**任意** $A$ 成立，不需方、不需对称。$\mathbf{Hilb}_{\text{fd}}$ 态射的极分解。

---

## 11.1 SVD 定理

$A=U\Sigma V^\top$（$U_{m\times m}$ 正交，$V_{n\times n}$ 正交，$\Sigma_{m\times n}$ 对角）。

奇异值 $\sigma_i=\sqrt{\lambda_i(A^\top A)}$。$\sigma_1\ge\cdots\ge\sigma_r>0$（$r=\mathrm{rank}\,A$）。

**三步分解**：$V^\top$ 旋转输入 → $\Sigma$ 拉伸 → $U$ 旋转输出。

```python
A = np.array([[1, 3], [2, 1]]); U, s, Vt = np.linalg.svd(A)
circle = np.array([[np.cos(t), np.sin(t)] for t in np.linspace(0, 2*np.pi, 200)])

fig, axes = plt.subplots(1, 4, figsize=(20, 5))
transforms = [circle, (Vt @ circle.T).T, (np.diag(s) @ Vt @ circle.T).T, (U @ np.diag(s) @ Vt @ circle.T).T]
titles = ['单位圆', 'V^T: 旋转', f'Σ: 缩放 σ=({s[0]:.1f},{s[1]:.1f})', 'U: 最终旋转']
for ax, data, title in zip(axes, transforms, titles):
    ax.fill(data[:,0], data[:,1], alpha=0.3); ax.plot(data[:,0], data[:,1], 'b-')
    ax.set_aspect('equal'); ax.set_xlim(-5,5); ax.set_ylim(-5,5); ax.set_title(title); ax.grid(True)
plt.tight_layout(); plt.show()
```

```mathematica
(* SVD三步 *)
A = {{1,3},{2,1.}}; {U,S,V} = SingularValueDecomposition[A];
circle = Table[{Cos[t],Sin[t]},{t,0,2Pi,0.01}];
steps = {circle, Transpose[V].#&/@circle,
  (Diagonal[Diagonal[S]].#&/@Transpose[V].#&/@circle),
  (U.Diagonal[Diagonal[S]].Transpose[V].#&/@circle)};
GraphicsRow[Table[ListLinePlot[s, AspectRatio->Automatic, PlotRange->5], {s, steps}]]
```

## 11.2 几何与变分意义

单位球在 $A$ 下的像 = 超椭球，半轴方向 = $U$ 的列，半轴长度 = $\sigma_i$。

$\sigma_1=\max_{\|x\|=1}\|Ax\|$，依次在正交约束下最大化。

```python
A = np.array([[2, 1], [0, 3]]); U, s, Vt = np.linalg.svd(A)
circle = np.array([[np.cos(t), np.sin(t)] for t in np.linspace(0, 2*np.pi, 200)])
transformed = (A @ circle.T).T

fig, ax = plt.subplots(figsize=(7,7))
ax.fill(transformed[:,0], transformed[:,1], alpha=0.2, color='red')
ax.plot(transformed[:,0], transformed[:,1], 'r-', linewidth=2)
for i in range(2):
    ax.quiver(0, 0, s[i]*U[0,i], s[i]*U[1,i], angles='xy', scale_units='xy', scale=1, color='purple', width=0.05)
    ax.quiver(0, 0, -s[i]*U[0,i], -s[i]*U[1,i], angles='xy', scale_units='xy', scale=1, color='purple', width=0.05, alpha=0.3)
ax.set_aspect('equal'); ax.set_xlim(-5,5); ax.set_ylim(-5,5)
ax.set_title(f'椭圆半轴 = σᵢuᵢ, σ₁={s[0]:.1f}, σ₂={s[1]:.1f}'); ax.grid(True)
plt.show()
```

```mathematica
(* SVD 椭圆 *)
A = {{2,1},{0,3}}; {U,S,V}=SingularValueDecomposition[A];
ParametricPlot[A.{Cos[t],Sin[t]},{t,0,2Pi},
  Epilog->{Purple,Arrow[{{0,0},S[[1,1]]*U[[All,1]]}],Arrow[{{0,0},S[[2,2]]*U[[All,2]]}]},
  AspectRatio->Automatic,PlotRange->5]
```

## 11.3 低秩逼近 (Eckart-Young)

$A_k=\sum_{i=1}^k\sigma_i u_i v_i^\top$ = 最近秩-$k$ 矩阵（在 $\|\cdot\|_2$ 和 $\|\cdot\|_F$ 下）。

**应用**：图像压缩（保留 $\le 10\%$ 奇异值即可高质量重构）。

```python
# 图像压缩 = 低秩SVD
from scipy.linalg import svd
x, y = np.linspace(-3, 3, 60), np.linspace(-3, 3, 60)
X, Y = np.meshgrid(x, y)
img = np.exp(-(X**2+Y**2))*np.cos(3*X)*np.sin(2*Y)
U_img, s_img, Vt_img = svd(img)

fig, axes = plt.subplots(1, 4, figsize=(18, 5))
for ax, k in zip(axes, [1, 3, 5, 10]):
    approx = U_img[:,:k] @ np.diag(s_img[:k]) @ Vt_img[:k,:]
    ax.imshow(approx, cmap='coolwarm'); ax.set_title(f'k={k}'); ax.axis('off')
plt.suptitle(f'SVD图像压缩 (原始rank={np.linalg.matrix_rank(img)})')
plt.tight_layout(); plt.show()
```

```mathematica
(* SVD图像压缩 *)
img = Table[Exp[-(x^2+y^2)]*Cos[3x]*Sin[2y],{x,-3,3,0.1},{y,-3,3,0.1}];
{U,S,V}=SingularValueDecomposition[img];
GraphicsRow[Table[MatrixPlot[U[[;;,;;k]].DiagonalMatrix[S[[;;k]]].Transpose[V[[;;,;;k]]]],{k,{1,3,5,10}}]]
```

---
**范畴论**：SVD = $\mathbf{Hilb}_{\text{fd}}$ 态射的极分解 $T=U\circ\Sigma\circ V^\dagger$。$\mathbf{Vect}_k$ 只有满-单分解。SVD 比 Jordan 形更普适——任意态射恒存在且唯一。$\Sigma$ 对角态射，"对角化任意态射"的能力来自 $\mathbf{Hilb}_{\text{fd}}$ 的内积结构。
