# 第 4 章：行列式

> $\det$ 是外幂函子 $\Lambda^n$ 的一维分量。$\det A\neq 0\iff\ker A=0\iff A$ 可逆。

---

## 4.1 公理化定义

行列式 $\det:M_n(k)\to k$ 由三条公理唯一刻画：
1. **列多重线性**：对每一列线性
2. **列交错性**：交换两列变号
3. **规范性**：$\det(I)=1$

**Leibniz 公式**：$\det A=\sum_{\sigma\in S_n}\mathrm{sgn}(\sigma)\prod a_{i,\sigma(i)}$。

$n=2:\;ad-bc$。$n=3:$ Sarrus 法则（三条正对角线和 − 三条反对角线和）。

**几何意义**：$|\det A|$ 是列向量张成平行多面体的**有向体积**。

**本章代码约定**（下文示例沿用这两个导入）

```python
import numpy as np
import matplotlib.pyplot as plt
```

```python
# 可视化：det = 有向面积
def plot_det(a, b, c, d):
    fig, ax = plt.subplots(figsize=(6,6))
    v1 = np.array([a, c]); v2 = np.array([b, d])
    det_val = a*d - b*c
    ax.fill([[0,0], v1, v1+v2, v2], color=('blue' if det_val>0 else 'red'), alpha=0.3)
    ax.quiver(0, 0, v1[0], v1[1], angles='xy', scale_units='xy', scale=1, color='b', width=0.04)
    ax.quiver(0, 0, v2[0], v2[1], angles='xy', scale_units='xy', scale=1, color='r', width=0.04)
    ax.set_xlim(-1, 5); ax.set_ylim(-1, 5); ax.set_aspect('equal')
    ax.set_title(f'det = {det_val:.0f} (面积 = {abs(det_val):.0f})'); ax.grid(True)
    plt.show()

plot_det(3, 1, 1, 2)  # det = 5
```

## 4.2 核心性质

$\det(AB)=\det A\cdot\det B$（**乘法性**——函子律的体现）。

$\det(A^\top)=\det A$，$\det(A^{-1})=1/\det A$。三角矩阵 $\det=\prod a_{ii}$。

$\det(P^{-1}AP)=\det A$（相似不变）。块对角：$\det\mathrm{diag}(A,B)=\det A\cdot\det B$。

**可逆判定**：$\det A\neq0\iff\mathrm{rank}\,A=n\iff\ker A=\{0\}\iff 0\notin\mathrm{Spec}(A)$。

```python
# 验证乘法性与体积缩放
np.random.seed(42); A,B = np.random.randn(3,3), np.random.randn(3,3)
print(f'det(AB)={np.linalg.det(A@B):.6f} = det(A)·det(B)={np.linalg.det(A)*np.linalg.det(B):.6f}')

# 不同变换对单位圆的面积缩放
fig, axes = plt.subplots(1, 3, figsize=(15,5))
circle = np.array([[np.cos(t), np.sin(t)] for t in np.linspace(0, 2*np.pi, 200)])
transforms = [(np.array([[2,0],[0,1]]),'拉伸 (det=2)'),
              (np.array([[1,0.5],[0,1]]),'剪切 (det=1)'),
              (np.array([[1,2],[2,1]]),'不定 (det=-3)')]
for ax, (T, title) in zip(axes, transforms):
    transformed = (T @ circle.T).T
    ax.fill(circle[:,0], circle[:,1], alpha=0.15, color='blue')
    ax.fill(transformed[:,0], transformed[:,1], alpha=0.3, color='red')
    ax.set_aspect('equal'); ax.set_xlim(-4,4); ax.set_ylim(-4,4)
    ax.set_title(f'{title}'); ax.grid(True)
plt.tight_layout(); plt.show()
```

## 4.3 Vandermonde 与特殊行列式

$\det(x_i^{j-1})=\prod_{i<j}(x_j-x_i)$。非零 $\iff$ 所有 $x_i$ 互异 → 多项式插值唯一。

**Cauchy 行列式**：$\det(1/(x_i+y_j))=\prod_{i<j}(x_j-x_i)(y_j-y_i)/\prod_{i,j}(x_i+y_j)$。

```python
# Vandermonde 与多项式插值
x_pts = np.array([0, 1, 2, 3]); V = np.vander(x_pts, increasing=True)
y_pts = np.sin(x_pts*np.pi/3) + 0.2*np.random.randn(4)
coeffs = np.linalg.solve(V, y_pts)

x_plot = np.linspace(-0.5, 3.5, 200)
y_interp = np.polyval(coeffs[::-1], x_plot)
fig, ax = plt.subplots(figsize=(8,5))
ax.scatter(x_pts, y_pts, s=80, c='red', zorder=5, label='插值节点')
ax.plot(x_plot, y_interp, 'b-', linewidth=2, label=f'插值多项式 (det(V)={np.linalg.det(V):.0f}≠0)')
ax.set_xlabel('x'); ax.set_ylabel('y'); ax.legend(); ax.grid(True)
ax.set_title('Vandermonde 行列式 ≠ 0 → 插值多项式存在唯一')
plt.show()
```

## 4.4 计算方法

| 方法 | 复杂度 | 适用 |
|---|---|---|
| Laplace 展开 | $O(n!)$ | $n\le4$ |
| LU: $\det=\prod u_{ii}\times(-1)^{\#\text{swaps}}$ | $O(n^3)$ | 通用 |
| Cholesky: $\det=(\prod\ell_{ii})^2$ | $O(n^3/3)$ | 对称正定 |
| 特征值: $\det=\prod\lambda_i$ | $O(n^3)$ | 已算特征值时 |

`slogdet` = (sign, log|det|) 避免上溢/下溢，大矩阵必备。

```python
# slogdet vs det
n = 500; M = np.random.randn(n,n) + 3*np.eye(n)
sign, logdet = np.linalg.slogdet(M)
try: d = np.linalg.det(M)
except: d = float('inf')
print(f'det 直接: {d:.2e}, slogdet: sign={sign:.0f} * exp({logdet:.1f}) = {sign*np.exp(logdet):.2e}')
```


**范畴论**：$\det$ 是 $\Lambda^{\dim V}:\mathbf{Vect}_k\to\mathbf{Vect}_k$ 函子在一维空间上的作用——$\Lambda^n(T):\Lambda^n V\to\Lambda^n V$ 就是标量乘法 $\det T$。$\det(AB)=\det A\cdot\det B$ 是函子律。$\det$ 是 $\mathbf{GL}_n\to k^\times$ 的群同态，其核 $\mathbf{SL}_n$ 是单模群。
